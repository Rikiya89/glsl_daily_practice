**[English](./README.md) | [日本語](./README.ja.md)**

**Rikiya Okawa** による継続的な制作記録です。2D パターンの実験から、レイマーチングによる 3D 表現、プロシージャルな生物表現、縦型動画を意識したループアニメーションへと発展しています。

## TouchDesigner での実行方法

**動作環境：** GLSL TOP を利用できる TouchDesigner と、対応する GPU・グラフィックスドライバが必要です。比較的新しい TouchDesigner を推奨しますが、`.toe` の互換性は保存時のバージョンに依存します。`.frag` ファイルの利用に Node.js やビルド作業は必要ありません。

**方法 A：プロジェクトを開く**

TouchDesigner で [`toe/20261020.toe`](./toe/20261020.toe) を開きます。バージョンの不一致などで開けない場合や、最小構成で試したい場合は方法 B を利用してください。

**方法 B：個別のシェーダを読み込む**

1. TouchDesigner で **GLSL TOP** を作成します。
2. **Text DAT** または **File In DAT** を作成し、任意の `.frag` ファイルを貼り付けるか読み込みます。
3. GLSL TOP の **Pixel Shader** に DAT を指定します。
4. **Common** ページで出力解像度を設定します。
5. シェーダ内で宣言されている uniform を確認し、必要な値を **Uniforms** ページで設定・バインドします。
6. コンパイルエラーとファイル冒頭の説明を確認してから、パラメータや解像度を調整します。

アニメーション用の時間値には、一般的に TouchDesigner の `absTime.seconds` を利用できます。ただし、**uniform 名は各シェーダの宣言と完全一致させる必要があります**。

| uniform 名 | 設定値の例 |
| --- | --- |
| `uTimeSeconds`（2026年の多くの作品） | Float：`absTime.seconds` |
| `uTime` / `u_time`（初期の作品） | Float：`absTime.seconds` |
| `uResolution` / `u_resolution`（宣言されている場合） | Vec2：GLSL TOP の幅と高さ |
| `uAudio`（宣言されている場合） | オプションのオーディオ信号。通常は 0〜1 に正規化 |

GLSL TOP の名前が `glsl1` の場合、解像度には `op('glsl1').width` と `op('glsl1').height` を使用できます。一方、新しい作品の一部では TouchDesigner 標準の `uTDOutputInfo.res.zw` から解像度を参照するため、独自の解像度 uniform は不要です。

**注意：** GLSL 側で uniform を宣言しただけでは、TouchDesigner 側の値は自動的に設定されません。必要な uniform を適切にバインドしてください。時間値が未設定の場合、アニメーションが静止することがあります。

### 定数制御と外部 uniform 制御

最近の作品には次の定義を持つものがあります。

```glsl
#define EXTERNAL_CONTROLS 0
```

`0` の状態では `CONTROL(...)` のパラメータはシェーダ内の定数として扱われ、コード内で直接調整できます。`1` に変更すると外部 uniform 制御に切り替わりますが、**必要なすべてのパラメータを TouchDesigner 側で設定してから**有効にしてください。`uTimeSeconds` などの時間 uniform は別途バインドする必要があります。

出力に `TDOutputSwizzle(vec4(...))` を利用するファイルは TouchDesigner 固有の記述を含みます。また、座標系は `gl_FragCoord`、`vUV`、TouchDesigner 標準の出力情報など作品ごとに異なります。移植や再利用の際は各ファイルを確認してください。

## 技術・表現テーマ

- **プロシージャルジオメトリ：** SDF、レイマーチング、反復構造、再帰的形状、数学的曲面
- **パターン生成：** ノイズ、FBM、ドメインワーピング、万華鏡、マンダラ、準結晶に着想を得た対称性
- **質感とライティング：** プロシージャルマテリアル、法線、フレネル効果、グロー、トーンマッピング
- **アニメーション：** 周期関数、カメラワーク、作品ごとに設計したシームレスループ
- **映像制作：** 一部の2026年作品は 1080 × 1920 などの縦型構図を想定。ただし、実際の出力解像度とフレームレートは TouchDesigner の設定で決まります。

複雑なレイマーチング表現は GPU 負荷が高くなる場合があります。再生が遅い場合は、まず GLSL TOP の解像度を下げ、必要に応じて各ファイルの反復回数や品質設定を確認してください。

## 他の環境への移植

GLSL の数式やアルゴリズムは Unity / HLSL などにも応用できますが、このリポジトリの主要な実行環境は **TouchDesigner GLSL TOP** です。移植時には uniform、スクリーン座標、テクスチャ入力、出力関数、GLSL 固有の組み込み機能などの調整が必要になることがあります。
